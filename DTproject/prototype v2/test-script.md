# Test Script: การทดสอบใช้งาน Prototype v1 (บอร์ดวัยเก๋าแบบยึดมั่น)

*สวนธนบุรีรมย์ — Design Thinking Project*

---

## ส่วนที่ 1: Pre-test (ก่อนเริ่มทดสอบ)

1. ปกติเวลามาสวน มาช่วงไหน เดินเส้นทางไหนบ้าง
2. เคยเห็นบอร์ดแบบนี้ในสวนไหม เคยใช้ไหม
3. ถ้าอยากหาเพื่อนทำกิจกรรม หรืออยากรู้ข่าวสารในสวน ปกติทำยังไง

---

## ส่วนที่ 2: Task-based Testing (ให้ลองใช้จริงหน้าบอร์ด)

*ตั้งเป็นคำถามเชิงสถานการณ์ ให้ผู้ใช้ **พูดและลงมือทำไปพร้อมกัน** โดย **ไม่บอกวิธีใช้ล่วงหน้า** แล้วสังเกตพฤติกรรมจริง*
 
| คำถามชวนทำ (Scenario Question) | สิ่งที่ต้องสังเกต |
| :--- | :--- |
| "ถ้าอยากหาเพื่อนมาออกกำลังกายด้วยกัน คุณจะลองทำยังไงกับบอร์ดนี้ ลองทำให้ดูหน่อย" | หาช่อง "หาเพื่อน" เจอไหม ใช้เวลานานแค่ไหน สับสนตรงไหน |
| "สมมติอยากประกาศหาเพื่อนออกกำลังกายสักคน คุณจะเขียนและแปะข้อความยังไงบนบอร์ดนี้" | หยิบเครื่องเขียนเจอไหม เขียนแล้วลังเลไหม แปะถูกโซนไหม |
| "บอร์ดตัวนี้เข็นย้ายที่ได้ ลองจับดูได้เลย — คุณคิดว่าควรเอาไปตั้งตรงไหนของสวน" | กล้าลองเข็นเองไหม จับตรงไหน หนักไหม บอร์ดโยกหรือมั่นคง เลือกจุดไหนและเพราะอะไร |
| "ถ้าอยากบอกเจ้าหน้าที่ว่าห้องน้ำโซนนั้นไฟดับ จะทำยังไง" | หากล่อง Feedback บนโต๊ะสามขาเจอไหม เข้าใจจุดประสงค์ไหม กล้าเขียนไหม |
 
**ระหว่าง task ให้จดบันทึก:**
- จุดที่ลังเล/สับสน (hesitation point)
- คำพูดที่หลุดออกมาขณะทำ (think-aloud)
- เวลาที่ใช้ต่อ task (time on task)

## ส่วนที่ 3: Post-test Interview (หลังลองใช้)

1. รู้สึกยังไงตอนใช้บอร์ดนี้ครั้งแรก *(How)*
2. มีจุดไหนที่ทำให้งงหรือไม่แน่ใจว่าต้องทำอะไรต่อ เล่าให้ฟังหน่อย *(What)*
3. การที่บอร์ดตัวนี้ย้ายที่ได้ คุณมองว่ายังไงบ้าง *(How)*
4. คิดว่าโซนแบ่ง "หาเพื่อน / กิจกรรม / แบ่งปันความรู้" ชัดเจนพอไหม อยากให้ปรับตรงไหน *(What)*
5. ถ้าบอร์ดย้ายตำแหน่งบ่อยๆ คุณคิดว่าจะเกิดอะไรขึ้นบ้าง *(What)*
6. เทียบกับตอนนี้ที่ยังไม่มีบอร์ดนี้ คุณคิดว่ามันช่วยแก้ปัญหาเรื่องหาเพื่อน/ความเหงาได้จริงไหม *(Why)*
7. กล่องรับความคิดเห็นที่วางข้างบอร์ด คุณคิดว่าจำเป็นไหม จะใช้จริงไหม *(Why)*
8. ถ้าบอร์ดนี้ตั้งอยู่จริงในสวน คุณคิดว่าจะกลับมาใช้อีกไหม เพราะอะไร *(Why)*

## ส่วนที่ 4: Wrap-up

- ให้คะแนนเรื่องการเคลื่อนย้ายได้ (ว่าเป็นประโยชน์แค่ไหน) 1–5
- ให้คะแนนความมั่นใจว่าจะหาบอร์ดเจอในครั้งถัดไป 1–5

# ทุกคนต้องสร้าง Branch ของตัวเอง

วิธีสร้าง:

1. สร้างและย้ายไปยัง branch ใหม่:

```bash
git switch -c <branch-name>
```

2. ตรวจสอบรายชื่อ branch:

```bash
git branch --list
```

หมายเหตุ: ใช้ชื่อ branch ชื่อของตัวเอง เช่น Chidpong
